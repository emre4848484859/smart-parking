# Wokwi Simülasyon Projesi

Bu klasör, VS Code Wokwi uzantısının otomatik olarak tanıyacağı sabit proje yapısını içerir:

- `diagram.json`: ESP32 + 2×74HC595 + CD74HC4067 + 10×HC-SR04 bağlantı şeması
- `code/main.ino`: `hardware/esp32_parking.ino` dosyasının birebir kopyası
- `project.json`: Proje meta verileri

Simülasyonu başlatmak için VS Code komut paletinde `Wokwi: Start Simulator` komutunu çalıştırın.
